# Each non-comment line is an extended POSIX regex (ERE). Empty lines and
# lines starting with `#` are ignored.

# The .githooks/pre-commit hook scans the staged diff (added lines only)
# against every pattern here. If any pattern matches, the commit is rejected
# with a clear error.
#
# To override for a single commit (use sparingly):
#     git commit --no-verify ...
#
# To update this list, add/edit patterns below. Patterns are case-sensitive.
# New patterns take effect on the next commit immediately.
#
# Design principle: this list is for TRULY SENSITIVE content (corp-internal,
# personal info, secrets) that should never reach a public commit. Brand /
# style regressions (e.g. old project names) are NOT blocked here — those are
# a quality issue, not a compliance issue, and would create false positives
# in legitimate places (migration scripts, CHANGELOG history entries).
